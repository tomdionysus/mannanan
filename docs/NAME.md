# Manannan - Name

Manannan mac Lir was the Irish god of the sea, navigation and the shifting boundary between worlds. The project bears his name because it keeps network destinations reachable as addresses change—maintaining a reliable route through an otherwise uncertain landscape.

You can read more about the mythology at Wikipedia - [Manannán mac Lir](https://en.wikipedia.org/wiki/Manann%C3%A1n_mac_Lir)
